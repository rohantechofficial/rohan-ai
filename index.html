Publish it free — Vercel + Google

This page is a single static file, ready for free hosting. Two steps put it on the open web and into Google Search.

Status: not yet deployed — the Vercel step needs your GitHub sign-in (github.com/rohantechofficial), which only you can complete. This build is the exact file that deploys; no changes are needed before importing it.

1 · Deploy on Vercel (free)

  1. Put this index.html in a GitHub repo
  2. vercel.com → New Project → import the repo
  3. Deploy — you get a free link like rohan-ai.vercel.app
Open Vercel deploy →

2 · Submit to Google

  1. Open Google Search Console, add the Vercel URL as a property
  2. Verify ownership with the HTML tag method
  3. Use “Request Indexing” — Google usually lists it in 2–7 days
Open Search Console →

3 · Go fully live (MP4)

For downloadable MP4 videos, connect a fal.ai key (Flux images + Kling video) on the server side. Until then, images download as PNG and videos play as animated previews.
